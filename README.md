# آموزش یار (Amoozeshyar) — نسخه ۲.۳.۱۰

اپلیکیشن آموزشی جامع فارسی (وب، فایل مستقل آفلاین و اپلیکیشن اندروید) برای یادگیری گام‌به‌گام دروس ریاضی و زبان انگلیسی از سطح صفر تا پیشرفته، همراه با درسنامه‌های رنگی، آزمایشگاه‌های بصری و تعاملی، فرمول‌های هر درس، تمرین‌های هدفمند و آزمون‌های تحلیلی.

## دروس ارائه‌شده

1. **ریاضی پایه هشتم (کامل)** — ۹ فصل کامل با درسنامه رنگی، آزمایشگاه تعاملی، فرمول‌ها، تمرین و آزمون.
2. **ریاضی ۱ — پایه دهم (نظری: ریاضی و فیزیک و علوم تجربی)** — ۷ فصل کامل (۲۳ درس) همراه با درسنامه جامع، فرمول‌ها، تمرین‌های چندسری و آزمون فصل.
3. **زبان انگلیسی (American English File 1 — فوق‌برنامه)** — ۱۲ فصل، ۴۸ درس، ۷۲۰ تمرین تعاملی و اتصال آنلاین یا آفلاین به ۴۰۱ فایل صوتی و ویدیویی کتاب کار، کتاب درسی، بخش‌های عملی و مرور.

## امکانات کلیدی

- **پروفایل تحصیلی هوشمند:** نمایش دروس صفحه اصلی و مخزن دروس بر اساس مقطع، پایه، شاخه و رشته تحصیلی کاربر (دروس فوق‌برنامه در همه مقاطع فعال هستند).
- **نمایش استاندارد کسرهای ریاضی:** رندر خودکار کسرهای ریاضی به‌صورت عمودی با صورت، خط کسری و مخرج در درسنامه، تمرین، آزمون و برگه چاپ.
- **ماشین‌حساب علمی و برگه‌های فرمول:** دسترسی مستقیم از نوار بالای دروس ریاضی بدون همپوشانی با محتوا.
- **کتابخانه صوتی و ویدیویی دوحالته:** اتصال مستقیم اینترنتی به سرور رسانه گیت‌هاب یا بارگذاری فایل فشرده از اینترنت و حافظه دستگاه.
- **تمرین‌های قفل‌شونده هوشمند:** در صورت ۳ بار پاسخ اشتباه، پاسخ صحیح و راه حل تشریحی نمایش داده شده و سؤال تا پایان دور جاری قفل می‌شود.
- **آزمون تحلیلی و تغییر سؤالات:** امکان تولید مجموعه سؤالات جدید با دکمه «تغییر سؤالات آزمون»، نمایش نمره از ۲۰ و جدول کامل پاسخ‌نامه در پایان آزمون، و ذخیره خودکار پاسخ‌نامه‌ها برای بررسی‌های بعدی.
- **مدیریت اختصاصی دروس:** تفکیک کامل بخش بارگذاری آنلاین و محلی دروس در صفحه مدیریت دروس.
- **بروزرسانی تک‌کلیکی و مدیریت دکمه بازگشت در اندروید:** اسکریپت خودکار تنظیم پل بومی اندروید برای نصب مستقیم نسخه جدید داخل برنامه و مدیریت مرحله‌ای دکمه بازگشت گوشی با پنجره تایید خروج.

## دستورات ساخت و توسعه

### پیش‌نیازها
- Node.js نسخه ۲۰ یا ۲۲ به بالا
- Android Studio (برای ساخت فایل APK با Capacitor)

### نصب و اجرای محلی

```bash
npm install
npm run dev
```

### ساخت نسخه وب و فایل آفلاین مستقل

```bash
npm run build
BUILD_SINGLEFILE=1 npx vite build --outDir dist-singlefile
```

### تنظیم خودکار پل اندروید، ساخت و کپی در Capacitor

پس از اجرای این دستور، تنظیمات `MainActivity`، `AndroidManifest.xml`، `file_paths.xml` و نسخه `build.gradle` به‌صورت خودکار اعمال شده و خروجی وب در پوشه اندروید کپی می‌شود:

```bash
npm run android:copy
npx cap open android
```

### انتشار در گیت‌هاب و ساخت Release APK

```bash
git add .
git commit -m "chore: release v2.3.9"
git push origin main
node F:\Amozeshyar\release-apk.mjs
```
